## Упражнение 1. Hello Vue
Выведите заголовок с вашим именем, а под ним абзац с названием университета и курса. Данные должны браться из переменных. Добавьте кнопку, которая по клику меняет заголовок на «Заголовок изменён».

## Упражнение 2. Счётчик с границами и шагом
Сделайте счётчик, который начинается с 0 и имеет две кнопки: «Увеличить» и «Уменьшить». Значение не должно опускаться ниже 0 и подниматься выше 20 (блокируйте нужную кнопку на границе). Добавьте поле для числа, которое задаёт шаг (на сколько меняется счётчик за один клик). Начальное значение шага равно 1.

## Упражнение 3. Имя пользователя в реальном времени
Сделайте поле ввода имени пользователя. Под ним должно показываться приветствие, которое меняется по мере набора, и количество введённых символов. Кнопка «Регистрация» остаётся заблокированной, пока имя короче четырёх символов. Когда длина достигает 12 символов, количество символов становится красным.

## Упражнение 4. Блок, меняющий вид
Сделайте блок с текстом. Кнопка переключает блок между светлым и тёмным режимом с помощью :class. Текст на кнопке зависит от режима («Включить тёмный режим» или «Включить светлый режим»).
